                            Privacidade

                            Código do aparelhoPara os banimentos valerem de verdade, o Astra manda um código embaralhado deste aparelho (no PC, um resumo do ID do Windows e da placa-mãe; no celular, o do app; no navegador, um código aleatório). O servidor embaralha de novo antes de guardar: não dá para descobrir o número real a partir dele, e ele só é usado para banir quem quebra as regras.
